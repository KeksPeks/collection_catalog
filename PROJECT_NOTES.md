# Подсказки проекта

## 2026-08-26 — серверные изображения и файлы

- Сервер Collection Catalog работает по адресу `http://192.168.0.7:8000` в локальной сети.
- API изображений: `/api/items/{item_id}/images` и `/api/images/{image_id}`.
- API файлов: `/api/items/{item_id}/files` и `/api/files/{file_id}`.
- Flutter-клиент серверных медиа: `lib/core/api/server_media_service.dart`.
- Экран карточки предмета запрашивает серверные изображения и файлы, если `entry.id` содержит числовой ID серверного предмета.
- Серверные изображения показываются отдельной горизонтальной галереей.
- Серверные файлы показываются в разделе «Файлы»; нажатие открывает URL загрузки через системное приложение.
- Ошибка медиа-сервера не должна блокировать открытие карточки.

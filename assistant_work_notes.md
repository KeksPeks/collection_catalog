- При выборе загруженного каталога теперь открывается непосредственно список его предметов (`ItemsPage`), без промежуточной технической страницы `CollectionDetailPage`.

## 2026-09-01

### Исправление подключения приложения к серверу
- FastAPI работает на `0.0.0.0:8000`; LAN IPv4 компьютера `192.168.0.7`.
- Для Android адрес API по умолчанию изменён с `127.0.0.1` на `192.168.0.7:8000`.
- `COLLECTION_API_BASE_URL` по-прежнему может переопределить адрес через `--dart-define`.
- Коммит: `fb46aa13e64b7e5d0d27cf4d92512d30648c8080`.

### Исправления коллекций и каталогов
- `CollectionRepositoryApi` теперь объединяет серверные каталоги с локальными коллекциями Drift; локальные записи имеют приоритет. Поэтому скачанные каталоги должны отображаться в «Мои коллекции» даже при работающем API.
- Добавлена нормализация структуры каталогов `CatalogStructureDefaults`.
- Для пустых демонстрационных направлений добавлены разделы и подразделы.
- Для Pokémon TCG добавлен базовый набор из 12 карточек, чтобы загрузка создавала реальные предметы в локальной коллекции.
- Для LEGO, Pokémon TCG, бонистики, видеоигр, фильмов, фигурок и игровых дисков добавлены многоуровневые разделы с категориями.
- Нормализованная структура используется перед открытием каталога и перед его загрузкой на устройство.
- В «Избранном» удаляются старые невалидные ключи вроде `countries` и `Russia`; поддерживается миграция старых ключей каталогов.
- Исправлена защита миграции избранного от повторного цикла `revision`.

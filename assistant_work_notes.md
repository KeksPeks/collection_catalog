# Рабочие подсказки для продолжения

## 2026-08-26

### Выполнено
- Исправлен экран «Мои коллекции».
- При выборе загруженного каталога теперь открывается непосредственно список его предметов (`ItemsPage`), без промежуточной технической страницы `CollectionDetailPage`.
- Убрано лишнее описание «Каталог сохранён на устройстве» из карточки коллекции.
- Название загруженной коллекции синхронизируется с названием направления каталога по `templateId`.
- Для `coins` используется направление `numismatics`, поэтому «Нумизматика» больше не должна отображаться как «Монеты».
- Поиск в «Мои коллекции» работает по отображаемому синхронизированному названию.
- При открытии `ItemsPage` передаётся синхронизированное имя коллекции.
- Для многоколоночного режима сохранена компактная карточка с защитой от переполнения текста.

## 2026-09-01

### Исправление подключения приложения к серверу
- FastAPI работает на `0.0.0.0:8000`; LAN IPv4 компьютера `192.168.0.7`.
- Для Android адрес API по умолчанию изменён с `127.0.0.1` на `192.168.0.7:8000`.
- `COLLECTION_API_BASE_URL` по-прежнему может переопределить адрес через `--dart-define`.

### Исправления коллекций и каталогов
- `CollectionRepositoryApi` объединяет серверные каталоги с локальными коллекциями Drift; локальные записи имеют приоритет.
- Добавлена нормализация структуры каталогов `CatalogStructureDefaults`.
- Для демонстрационных направлений используются осмысленные разделы и категории вместо технических названий.
- Для конструкторов добавлена иерархия: **производитель → серия → категория**. В образцах представлены LEGO, COBI, CaDA, BlueBrixx и MEGA.
- Для Pokémon TCG сохранён базовый набор карточек с привязкой к разделам серий и типов карт.
- Для нумизматики верхний уровень теперь является **Страны**, а внутри страны идут категории чеканки и дальнейшая детализация.
- В «Каталоге» нумизматика сразу показывает страны, без технического раздела «Страны».
- В «Избранном» при наличии избранной нумизматики показываются непосредственно страны с переходом в соответствующую ветку каталога.
- В «Моих коллекциях» убрано техническое сообщение «Фильтры появляются только на уровне предметов»; экран сразу показывает дерево разделов.
- В «Избранном» удаляются старые невалидные ключи вроде `countries` и `Russia`.

### Проверка
- Текущая работа выполняется в `develop`.
- Требуется локальная проверка №1: в начале проверки указывать путь `D:\FlutterProjects\collection_catalog`; затем `flutter clean`, `flutter pub get`, `flutter analyze`, `flutter run`.
- После исправления найденных ошибок выполнить проверку №2 тем же циклом.
- Только после двух успешных проверок переносить изменения в `main`.

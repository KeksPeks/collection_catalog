# Collection Catalog — журнал изменений для продолжения работы

Этот файл предназначен как рабочая памятка для продолжения проекта. Здесь фиксируются только подтверждённые изменения, решения пользователя и незавершённые задачи. Даты указаны по истории проекта и текущим действиям.

## 2026-08-25 — текущий этап

### Выполнено и подтверждено пользователем
- Основная рабочая ветка для продолжения: `develop`.
- После предыдущих конфликтов интеграционная ветка была очищена отдельно; локальный старый merge не используется.
- Сборка была успешно запущена перед продолжением работ.
- Исправлена синтаксическая ошибка в `lib/app/collection_catalog_app.dart`, из-за которой `flutter analyze` выдавал `Expected to find ')'`.
- Из интерфейса убирается идея фиксированной высоты карточек: размеры должны зависеть от доступной ширины и текста.
- Настройки интерфейса должны находиться в обычных настройках, а не в «Инструментах коллекционера».
- Настройки колонок должны быть общими для каталога, избранного и моих коллекций.
- Размеры колонок не должны быть отдельной пользовательской настройкой высоты карточек.
- При слишком большом количестве колонок текст не должен вызывать `Bottom overflowed`; если текст не помещается, карточка должна показывать только значок.
- Внесена адаптация карточек категории каталога: при нескольких колонках значок и название центрируются; если название не помещается по ширине, остаётся только значок.
- В избранном убрана принудительная большая высота карточек; карточки стали компактными и проверяют, помещается ли текст.
- В «Мои коллекции» сеточные карточки сделаны компактными; при нехватке ширины название скрывается и остаётся значок, чтобы исключить `Bottom overflow`.
- Добавлен локальный экран `OverviewPage`: статистика и достижения рассчитываются на устройстве через локальную базу данных и не требуют сервера.
- Добавлены первые локальные достижения: первый шаг, 10 предметов, 100 предметов, 5 коллекций, 1000 предметов.

## Что было отменено / больше не использовать
- Старый локальный merge с конфликтами между `main` и интеграционной веткой.
- Фиксированную пользовательскую высоту карточек.
- Изменение размеров карточек через «Инструменты коллекционера».
- Серверную зависимость для достижений: геймификация должна работать полностью локально.

- Комментарии в коде — на русском.
- Перед каждой проверкой явно указывать путь к проверяемому файлу/проекту.

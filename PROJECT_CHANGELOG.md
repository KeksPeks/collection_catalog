# Collection Catalog — журнал изменений для продолжения работы

## 2026-08-25 — интерфейс, обзор и адаптивная сетка

### Выполнено
- Восстановлен раздел «Обзор» в основной навигации.
- «Обзор» работает на локальных данных устройства и не требует сервера.
- В «Обзоре» отображаются статистика коллекций, предметов и достижения.
- Расчёт количества предметов в обзоре переведён на параллельную загрузку.
- Добавлены достижения «Ветеран» и «Легенда».
- Убрана отдельная настройка «Размер интерфейса».
- Убрана пользовательская настройка количества колонок.
- Высота карточек каталога рассчитывается адаптивно.
- При нехватке ширины название карточки скрывается, остаётся только значок.
- Значок и название компактных карточек центрированы.
- Убран текст количества вида «1 выберите каталог».
- Избранные карточки сделаны компактнее и рассчитывают ширину по названию.
- В форме предложения изменения каталога номер версии скрыт из выбора каталога.

### Подтверждено пользователем
- Размер интерфейса как отдельную настройку не использовать.
- Колонки не задавать вручную — определять автоматически.
- Если текст не помещается, показывать только значок.
- «Обзор» должен быть полноценным разделом статистики и геймификации.
- Достижения должны работать полностью локально на телефоне.

### Не возвращать без отдельного запроса
- Фиксированную высоту карточек.
- Настройку размера интерфейса.
- Настройку количества колонок пользователем.
- Старый текст количества каталогов в категориях.
- Номер версии в селекторе каталога формы обратной связи.

### Требует проверки
- `flutter analyze`.
- `flutter run`.
- 1/2/3/4 колонки на Android.
- Bottom overflow.
- Избранное при разных размерах текста.
- Обзор и разблокировка достижений.
- Загрузка каталога и SQLite в «Моих коллекциях».
- После двух успешных проверок — `flutter build apk --debug`.
- После подтверждения — перенос результата в `main`.

## Правила проекта
- Рабочая ветка: `develop`.
- Сначала изменения и проверки в `develop`.
- После успешной проверки переносить результат в `main`.
- Изменения выполнять напрямую в GitHub.
- Локальная рабочая копия: `D:\FlutterProjects\collection_catalog`.
- Перед локальной проверкой синхронизировать рабочую копию с GitHub.
- Перед компиляцией сначала запускать `flutter run`.
- После новых функций или крупных правок проводить две полные проверки.

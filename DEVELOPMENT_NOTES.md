# Collection Catalog — заметки разработки

## 2026-09-01

### Подключение Flutter к существующему API

- Все изменения выполнены в ветке `develop`.
- Добавлен `lib/core/network/api_client.dart` на базе Dio.
- Добавлен `lib/features/collections/data/repositories/collection_repository_api.dart`.
- `collectionRepositoryProvider` теперь получает список коллекций из `GET /api/collections`.
- Локальный Drift-репозиторий сохранён как backend для текущих операций записи, чтобы не ломать существующее редактирование до появления API-команд записи.
- Идентификаторы серверных коллекций преобразуются в `String`, как требует текущая domain-модель Flutter.
- Ответ API передаётся Dio как JSON; Unicode не перекодируется вручную и должен отображаться в приложении корректно.
- Для Android добавлены `INTERNET` и разрешён HTTP-доступ к локальному серверу.
- Адрес API можно задать через `--dart-define=COLLECTION_API_BASE_URL=...`.
- Значение по умолчанию: `http://127.0.0.1:8000` (подходит для Windows/локального запуска; для физического Android-устройства нужен LAN-адрес ПК).

### Важно

- PostgreSQL данные не изменялись.
- Ручная перекодировка данных в БД не выполнялась.
- Сервер запускается отдельно перед проверкой.

# Server catalog importers

Все серверные импортеры Collection Catalog хранятся в этой директории.

## Серверное хранилище

Основной диск сервера: `G:`.

Корень данных: `G:\CollectionServer\`.

Репозиторий содержит код импортёров и документацию. Большие базы данных, изображения и загруженные bulk-файлы не должны помещаться в GitHub: они размещаются на серверном диске G:.

## Первый импортёр

- `mtg/scryfall_parser.py` — Magic: The Gathering / Scryfall.

## Порядок проверки

1. Проверить синтаксис Python.
2. Запустить импорт без изображений.
3. Проверить созданные файлы и количество записей на G:.
4. Выполнить вторую проверку импорта.
5. Только после успешной проверки добавлять загрузку изображений.
6. После успешной проверки develop изменения можно переносить в main.

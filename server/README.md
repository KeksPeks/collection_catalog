# Collection Catalog Server

Серверная часть Collection Catalog.

## Назначение

Сервер предоставляет клиенту каталог в режиме только чтения. Пользователь получает необходимые данные каталога и может скачивать связанные изображения и файлы.

Рабочие данные сервера не хранятся в GitHub:

- `G:\CollectionServer\database` — PostgreSQL и SQL-файлы;
- `G:\CollectionServer\images` — изображения каталога;
- `G:\CollectionServer\downloads` — дополнительные файлы;
- `G:\CollectionServer\collections` — локальные данные коллекций;
- `G:\CollectionServer\backups` — резервные копии;
- `G:\CollectionServer\logs` — журналы.

## Безопасность файлов

API файлов должен выдавать только объекты внутри:

- `G:\CollectionServer\images`
- `G:\CollectionServer\downloads`

Пути из БД являются относительными. Абсолютные пути и переходы через `..` запрещены.

## Режим публикации

На текущем этапе сервер предназначен для публичного скачивания каталога. Изменение пользовательских коллекций через этот API не предоставляется.

Рабочая схема разработки проекта: `develop` → проверка → `main`.
